# ⚖️ Legal House

A clean and informative static website providing an overview of various fields of law. This project serves as a digital resource for understanding different legal sectors, including Criminal Law, Tax Law, Divorce Law, and more.

</div>

---

## 🚀 Features

- **Topic-Specific Sections:** Dedicated information for various areas of law.
- **Responsive Layout:** Simple, clean design focused on readability.
- **Easy Navigation:** Quick access to essential legal information.

## 📂 Areas of Law Covered

- **Business Law:** Rules governing commercial interactions.
- **Criminal Law:** Understanding government-imposed rules and consequences.
- **Child Support:** Information regarding legal obligations for child care.
- **Education Law:** Regulations concerning academic institutions and rights.
- **Divorce Law:** Legal processes regarding the dissolution of marriage.
- **Tax Law:** Rules for government revenue collection and compliance.

## 🛠️ Technologies Used

- **HTML5:** Structuring the content.
- **CSS3:** Styling and layout design.

## 💡 How to Run Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/tuhin360/legal-house.git
   ```

2. **Open the project:**
   Navigate to the folder and simply open the `index.html` file in your preferred web browser.
